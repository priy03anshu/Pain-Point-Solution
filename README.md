PlacementOS — AI-Powered Placement Preparation Platform
Practice. Improve. Get Placement Ready.

PlacementOS is an AI-powered platform designed to help students prepare for placements through Group Discussion (GD) practice, quizzes, and skill-based preparation.

✨ Features
🗣️ GD Practice — Practice Group Discussion sessions and improve communication, confidence, and presentation skills.

🧠 Quizzes — Test your knowledge with quizzes covering technical and aptitude topics.

📚 Skill Preparation — Learn and improve the skills required for your target roles and placements.

🎯 Personalized Preparation — Identify weak areas and focus on skills that need improvement.

📊 Progress Tracking — Track your preparation and improvement over time.

🤖 AI-Powered Guidance — Get personalized feedback and recommendations.

🚀 Tech Stack

Frontend: Next.js, TypeScript, Tailwind CSS

Backend: Node.js, Express, TypeScript

AI Service: Python, FastAPI

Database: MongoDB

Cache/Queue: Redis, BullMQ

Authentication: JWT

🏃 Getting Started

Prerequisites

Node.js 18+

MongoDB

Python 3.10+

Installation

npm install

npm run build --workspace=packages/shared

npm run seed



Run

// one in a separate terminal 

npm run dev:api

npm run dev:web

npm run dev:ai


Open http://localhost:3000.

🐳 Docker

docker compose -f docker/docker-compose.yml up --build


🎯 Goal


PlacementOS brings GD practice, quizzes, and skill preparation into one platform to help students become more confident, skilled, and placement-ready.
